Control Methods (handwritten style)

CommandJoystick:
- getLeftX(): sol stick X ekseni, -1..1
- getLeftY(): sol stick Y ekseni, yukari +1 asagi -1
- getRightX(): sag stick X ekseni, -1..1
- getRightY(): sag stick Y ekseni, yukari +1 asagi -1
- getL2(): L2 analog trigger, 0..1
- getR2(): R2 analog trigger, 0..1
- getL1(): L1 dijital buton Trigger
- getR1(): R1 dijital buton Trigger
- getBtnDown(): face button alt (A / X)
- getBtnUp(): face button ust (Y / Triangle)
- getBtnLeft(): face button sol (X / Square)
- getBtnRight(): face button sag (B / Circle)
- getX(): PlayStation X (alt face button)
- getO(): PlayStation O (sag face button)
- getSquare(): PlayStation Square (sol face button)
- getTriangle(): PlayStation Triangle (ust face button)
- getPovCenter(): D-pad merkez (POV -1)
- getPovDown(): D-pad asagi (POV 180)
- getPovUp(): D-pad yukari (POV 0)
- getPovLeft(): D-pad sol (POV 270)
- getPovRight(): D-pad sag (POV 90)
- getPovDownLeft(): D-pad asagi-sol (POV 225)
- getPovDownRight(): D-pad asagi-sag (POV 135)
- getPovUpLeft(): D-pad yukari-sol (POV 315)
- getPovUpRight(): D-pad yukari-sag (POV 45)
